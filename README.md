# MoodMapper

**Аспектный анализ тональности русскоязычных отзывов прямо в браузере**

MoodMapper — это веб-приложение для детального анализа отзывов, которое работает **полностью на стороне клиента** и не требует серверной части. Вместо простого «отзыв позитивный или негативный», приложение выделяет **отдельные аспекты** (еда, сервис, доставка, цена, атмосфера…) и определяет тональность **каждого из них**.

> **Пример:**
> Ввод: `"Пицца была вкусной, но доставка опоздала на час"`
> Вывод: `пицца → ПОЗИТИВ`, `доставка → НЕГАТИВ`

## Возможности

| Функция | Описание |
|---------|----------|
| **Аспектный анализ** | Выделяет отдельные аспекты в тексте и определяет тональность каждого |
| **Одиночный режим** | Ввод текста вручную, мгновенный анализ, карточки аспектов |
| **Пакетный режим** | Загрузка CSV (`id,text`), обработка множества отзывов |
| **Прогресс-бар** | Отображение прогресса пакетной обработки в реальном времени |
| **Пауза и возобновление** | Возможность приостановить обработку и продолжить с того же места |
| **Отмена обработки** | Прерывание пакетной обработки на любом этапе |
| **Агрегация по отзывам** | Сводка по всей пакетке: сколько позитивных, негативных, смешанных отзывов |
| **Вердикт на каждый отзыв** | Определяется по большинству аспектов (позитив/негатив/смешанный) |
| **Топ-аспектов** | Самые частые аспекты с преобладающей тональностью |
| **Экспорт HTML-отчёта** | Красивый автономный HTML-файл со всей статистикой и деталями |
| **Скачивание шаблона CSV** | Готовый шаблон для быстрого старта |
| **Умное разбиение контекста** | Учёт точек, тире, союзов (`но`, `а`, `однако`), запятых |

## Технологии

| Компонент | Роль |
|-----------|------|
| **PyScript 2024.1.1** | Запуск Python в браузере через WebAssembly |
| **Pyodide 0.26.2** | Python-интерпретатор, скомпилированный в WASM |
| **Transformers.js.py** | Python-обёртка над JS-версией Hugging Face Transformers |
| **Модель** `Artemeey2/rubert-base-cased-sentiment-onnx` | Русскоязычная BERT-модель для анализа тональности (ONNX) |
| **Vanilla JS** | File API, Blob, URL.createObjectURL для работы с файлами |
| **HTML/CSS** | Минималистичный интерфейс без фреймворков |

**Почему именно так:**
- **Без бэкенда** — всё работает в браузере, не нужен сервер, хостинг дешёвый (или бесплатный)
- **Без Docker** — нечего контейнеризировать, нет серверных зависимостей
- **Без сборки** — нет Webpack/Vite, просто HTML + CSS + Python

## Формат CSV

Структура: id,text — без заголовков, разделитель — запятая, кодировка — UTF-8.

1,"Пицца была вкусной, но доставка опоздала на час"
2,"Обслуживание ужасное, больше не приду"
3,"Атмосфера приятная, музыка тихая, еда вкусная"
4,"Кофе холодный, десерт восхитительный"
5,"Всё отлично, рекомендую! Вернусь ещё"

## Этапы разработки

### Этап 1: Выбор концепции
Остановился на **аспектном анализе тональности** — практичная задача, работает с ML в браузере.

### Этап 2: Базовый каркас на PyScript
Создал `index.html`, `style.css`, `main.py`, `pyscript.json`.

### Этап 3: Поиск аспектов
Для поиска аспектов используется **свой словарь аспектов**.

### Этап 4: Контекст аспекта
Добавил разбиение текста, чтобы каждый аспект анализировался в своём контексте, а не в общем тексте.

### Этап 5: Агрегация и визуализация
Сводка по тональностям, прогресс-бар, карточки аспектов, топ-5 аспектов.

### Этап 6: Обработка нескольких предложений
Разбиение текста по точкам → тире → союзам → запятым. Каждый аспект получает свой минимальный контекст.

### Этап 7: Пакетный режим
Загрузка CSV (`id,text`), парсинг, валидация, прогресс-бар, пауза, отмена.

### Этап 8: Экспорт HTML-отчёта
Автономный HTML-файл со сводкой, топ-аспектами и деталями. Работает и в одиночном, и в пакетном режиме.

### Этап 9: Вердикт на каждый отзыв
В пакетном режиме показывается общий вердикт. Группировка по `review_id` и определение вердикта **по большинству аспектов**.

### Этап 10: Улучшение точности
Добавлены усилители (`очень`, `крайне`), веса маркеров, корневые формы.
